Provenance: workload `wikit` (Table 2 "WikiT")
==============================================

Source
  Wikimedia CDN, text (page-view) cluster, 2019 21-day trace, from the
  cacheMon open-source cache dataset, https://github.com/cacheMon/cache_dataset
  (CC-BY 4.0). File:
  https://cache-datasets.s3.amazonaws.com/cache_dataset_txt/2019_wiki/wiki/2019/wiki.txt.2019.zst

Record mapping
  TSV: relative_unix \t hashed_host_path_query \t response_size \t ttfb
  every row -> read (`key`), key = hashed_host_path_query. No pagination.

Sampling (spatial hash / SHARDS, kv_pipeline.py)
  keep request iff BLAKE2b-64(key, key="cloak1") / 2^64 < rate

  Stage 1, collect:
    rate               0.25
    max-keep cap       60,000,000 (not reached)
    raw lines read     207,646,002 (the whole file)
    requests kept      52,633,462
    distinct objects   4,599,865
    stop reason        input_exhausted
    trace time span    0 .. 1,814,399 s (relative timestamps) = 21.0 days

  Stage 2, regen:
    caps               10,000,000 requests / 1,250,000 distinct keys
    rate               0.0546875
                       (binary search for 1M distinct keys, tolerance 5%)
    stop reason        request_cap (the 10M requests cover roughly the
                       first 18 days of the 21-day trace)
